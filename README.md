# VAHINI WEDDINGS — fixed static demo

Open `index.html` to preview. Open `admin.html` for browser-local demo uploads. See `DEPLOY.md` for GitHub Pages.

Gallery: responsive masonry photos and film previews; film-only header toggle; image/video lightbox with arrows, Escape and swipe; dark/light toggle; left-aligned single-line brand.

This is a demo, not a production 20 TB storage solution. External sample assets require internet access. Uploaded files are saved in browser IndexedDB, not your GitHub repository or server.
